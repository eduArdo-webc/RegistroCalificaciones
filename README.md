# Registro de calificaciones

Programa en Python que usa funciones para registrar y analizar las calificaciones de un grupo.

Funciones:

1. `registrar_calificaciones()` - pide las calificaciones (solo de 0 a 10) y las guarda en una lista.
2. `mostrar_calificaciones(calificaciones)` - muestra todas las calificaciones.
3. `calcular_promedio(calificaciones)` - regresa el promedio del grupo.
4. `obtener_calificacion_mayor(calificaciones)` - regresa la calificacion mas alta.
5. `contar_aprobados(calificaciones)` - regresa cuantos aprobaron (6 o mas).

## Como correrlo

```
python registro_calificaciones.py
```
